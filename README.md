# Compra Binária

Projeto da faculdade, de dez/2022. Subi pro GitHub em novembro de 2026 só pra guardar, sem mexer no código.

Jogo de mercado que fiz pra praticar busca binária. Ele gera uma lista de compras, os alimentos vão aparecendo e você precisa colocar os itens certos no carrinho antes do tempo acabar. A busca está em `BuscaBinaria.cs`; timer, meta e textos da tela ficam no `Controlador.cs`.

## Como abrir

Abra a pasta do repositório pelo Unity Hub (Add project from disk). Usei o Unity 2020.3.36f1. A pasta Library não está no repositório; o Unity gera de novo na primeira vez que abre.

Outros projetos da faculdade: [projetos-da-faculdade](https://github.com/gustadimas/projetos-da-faculdade)
